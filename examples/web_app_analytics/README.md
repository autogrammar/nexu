# Web App Analytics Cinema Snapshot

This folder contains static Cinema HTML snapshots for a database analytics dashboard example.

Files:

- `cinema/stage0.html`
- `cinema/stage1.html`
- `cinema/stage2.html`
- `cinema/cinema_player.html`

Open `cinema/cinema_player.html` directly in a browser to inspect the saved visual evolution. This is a static snapshot, not the live Cinema server workflow. For live generation, use the calculator workspace from the repository root:

```bash
NEXU_CINEMA_NO_OPEN=1 make cinema
```
